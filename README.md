Entry for the [Worst Superpower](https://make.fun/competitions/u-suroto-worst-superpower-461dcdbe) competition on [make.fun](https://make.fun).

`main.py` (pure Python stdlib) writes one line — at most 140 characters — inventing the most useless superpower imaginable, to `/output/entry.txt`:

> I can freeze time for exactly one second, once in my life - and I already spent it this morning, sneezing into my cereal.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
